# Dual Scanner Station Visual Verification

The station-specific routes render independently and preserve the selected event ID. `?station=A&eventId=3390003` displays `Door A — dedicated scanner display · Event 3390003 · Zone N`; `?station=B&eventId=3390003` displays `Door B — dedicated scanner display · Event 3390003 · Zone E`. Both routes correctly show the no-data guard until the event dataset is loaded.
